# Start pannradhu eppadi

1. ZIP file-a **Extract All** pannu.
2. `resume_ai` folder open pannu.
3. Python 3.11 or 3.12 install pannirukkanum. Install pannumbodhu **Add Python to PATH** tick pannu.
4. `start_windows.bat` double-click pannu. First time packages download aagum; internet venum.
5. Browser-la `http://localhost:8501` open pannu.
6. **Create account** tab-la username + minimum 10-character password kuduthu register pannu. Apram sign in pannu.
7. Quick-a explore panna sidebar-la **Use demo resume** click pannu. Demo details unnudaiyadhu illa; apply pannumbodhu un resume use pannu.
8. **Resume workspace**-la resume upload panni **Read uploaded resume** click pannu. Text review pannitu **Save new version** click pannu.
9. **Job match**-la JD paste pannu. **Job library**-la jobs save pannu; **Applications**-la status update pannu.

AI tailoring, cover letter, mock interview, roadmap and career coach use panna sidebar **AI connection**-la Google Gemini API key + available Gemini model ID kudu. Consent checkbox tick pannu. API charges varalaam. Matha local features key illama work aagum.

**Mukkiyam:** live internet job search, automatic application submit, background email alerts indha version-la illa. Saved jobs-a match pannum; reminder dashboard-la kaatum. Ella included features and limits `README.md`-la irukku.

App close panna terminal-la Ctrl+C. Saved data `data` folder-la irukkum; atha delete pannatha. Settings-la backup download pannikkalam.
